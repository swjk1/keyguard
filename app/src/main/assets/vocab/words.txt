# Frequency-ordered English vocabulary for completion and prediction.
# Order IS the frequency rank - earlier is more common. Lines starting with # are ignored.
#
# The platform spell checker corrects misspellings but cannot predict or complete, so this
# has to ship. Kept deliberately small: ~1000 words covers the large majority of everyday
# typing, the user dictionary learns the rest, and a bigger list would cost APK size and
# lookup time for diminishing return.
#
# Includes ordinary chat and teen vocabulary on purpose - this product's users type "gonna"
# and "lol" far more often than they type "whereas".
